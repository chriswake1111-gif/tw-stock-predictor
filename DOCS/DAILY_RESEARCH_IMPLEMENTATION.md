# 每日研究流程實作追蹤

核准範圍：上市及上櫃普通股、收盤後研究、公開來源優先；完成搜尋 → 價量／基本面 → 人工假設確認 → 情境 → 快照／筆記 → 隔日複核。

## 交付階段

- A：既有修正整合、最近來源檢查節流、可中止的更新狀態、中文簡稱、安裝升級驗證。
- B：近一年／三個月價量、單季及 TTM EPS、PE／PB／殖利率、分項來源日期與品質、市場資料整合。
- C：本機安全假設入口、EPS／PE／錨點候選與輸入、預覽、核准、修改及撤銷。
- D：自選入口、部分研究保存、筆記、隔日比較與自動日期。

## 驗收邊界

程式測試、安裝測試、連續三個交易日驗收與使用者獨立操作分開記錄。
未完成全部驗收前，不將版本標記為「每日研究可用」。不降低資料真實性、核准或歷史截止時間規則。

## B–D 實作與資料契約

- 新增受 allowlist／capability／deadline 約束的 FinMind 價量、PER、逐季 EPS 來源；原始回應與標準化快照各保存 SHA-256。不是官方交易所資料；價格未還原權息、缺交易日未稽核，不自動補列。TTM 因跨季股數基準尚未驗證而維持缺值。
- 市場成交額使用 TWSE、TPEx 共同日期，M1B 以 CBC 類別名稱定位並轉為 TWD；各自顯示日期與更新結果。成功快取共用 30 分鐘，失敗項目可再次更新。
- 新增 `public_data`／`market_data` 摘要欄位與市場日期／CBC 期間；舊欄位相容。沒有更改金融公式、Rule ID 或證據分類。
- 本機假設入口位於既有 research 邊界，要求 loopback、Origin、CSRF、有效 launch handshake；不傳送管理金鑰。預覽不寫入，草稿不核准。EPS／PE／錨點分別呼叫既有 service；修改沿用既有 revision_of 規則，撤銷沿用現有核准服務。
- command journal 固定首次接受時間，配合既有 repository 冪等鍵支援中斷後重試；不得指定過去的核准時間。核准／撤銷不改寫舊研究。
- 當次研究與純文字筆記採 append-only journal，固定保存摘要、資料日期、知識截止、來源快照、模型版本與實際情境的核准依據。若同一截止已有完整分析快照則驗證並關聯；部分觀察不混入歷史快照人口，不宣稱歷史適用資格。
- 每日頁自動使用伺服器時間，比較前次保存結果；不同來源、缺值、日期倒退不算差異，假設改變獨立提示。原歷史 D/K 複核保留在進階區。

新增遷移 23／24／25，均為新增表格；安裝啟動沿用 StartupCoordinator 升級前備份，舊快照及財務表不覆寫。回退採安裝前備份與舊程式成對還原，不讓舊版直接寫入新格式。

## 寫入檢查（新增範圍）

| 寫入路徑 | 觸發／頻率 | 冪等與界限 | 保存／風險 |
|---|---|---|---|
| daily_public_snapshots | 明確或需更新的標的查詢 | 相同原始 SHA＋parser 不重寫；近一年價量、近兩年 EPS | immutable；不同日快照仍可能重複涵蓋歷史，容量中風險 |
| daily_public_attempts | 每次來源檢查 | 成功 30 分鐘快取；共享市場去重；不輪詢寫 DB | 保留失敗／檢查紀錄；長期容量需後續量測 |
| local_research_commands | 使用者保存／核准／撤銷 | 同 key 同 payload 返回原結果；無鍵盤 autosave | 小型持久紀錄；不自動清除 |
| daily_research_entries | 使用者明確保存 | note 上限 4,000 字；同 key 冪等；無閒置寫入 | 每筆保留當次摘要，股票數與保存次數會增加容量 |
| migration backup | 安裝升級 | 原版可讀備份後才新增 schema | 與舊程式配對回退；不能當作任意降版相容 |
