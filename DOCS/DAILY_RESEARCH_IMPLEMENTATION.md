# 每日研究流程實作追蹤

核准範圍：上市及上櫃普通股、收盤後研究、公開來源優先；完成搜尋 → 價量／基本面 → 人工假設確認 → 情境 → 快照／筆記 → 隔日複核。

## 交付階段

- A：既有修正整合、最近來源檢查節流、可中止的更新狀態、中文簡稱、安裝升級驗證。
- B：近一年／三個月價量、單季及 TTM EPS、PE／PB／殖利率、分項來源日期與品質、市場資料整合。
- C：本機安全假設入口、EPS／PE／錨點候選與輸入、預覽、核准、修改及撤銷。
- D：自選入口、部分研究保存、筆記、隔日比較與自動日期。

## 驗收邊界

程式測試、安裝測試、連續三個交易日驗收與使用者獨立操作分開記錄。

## 2026-09-11 進行中

## 寫入檢查（A 範圍）

| 項目 | 結果 |
|---|---|
| 本機寫入位置 | 既有 SQLite 作業、來源修訂與日誌；沒有新快取資料庫 |
| 高頻與閒置 | 進頁使用來源檢查節流；無新增閒置寫入 |
| SQLite | 保留既有原子版本接續、同內容冪等性；不刪舊來源 |
| 日誌 | DiagnosticLogger 預設單檔 10 MiB、邏輯上限 60 MiB；實際大量同步仍有逐筆稽核成本 |
| 暫存 | 驗證產物留在忽略的測試目錄，不進 Git；不自動刪使用者資料 |
| 保存／清理 | 正式來源追溯紀錄沿用既有保存政策；只清理日誌輪替檔 |
| 風險 | 中：來源全量同步仍有既有逐筆寫入成本；此次減少不必要重跑，尚非全系統容量稽核 |
