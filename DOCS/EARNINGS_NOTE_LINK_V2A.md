## Assessment 與行為差異

先前工具能讀取結構化財報中的每股盈餘，無法把完整財報附註中的獲利與加權平均股數對回同一期間。本步增加可重複執行的欄位核對，不以人工輸入「已驗證」取代來源證據。

現在可在支援的格式內讀出期間、基本／稀釋每股盈餘、對應盈餘、普通股加權平均股數、台幣與千股單位，保留頁碼、欄序及文字位置，再與指定內容雜湊的結構化財報比較。已解析、數值對得上、跨季可比是三件不同的事。

採窄格式處理：目前登錄昇達科中文調節表、台積電六月期中英文調節表、聯亞中文基本／稀釋分表。不是所有公司或同一公司所有年份通用的財報解析器；未知版型、期間順序、單位及欄位不符時停止該次核對。

## 重現與保存邊界

```powershell
python -X utf8 tools/audit_earnings_sources.py --manifest .tmp_earnings_v2_20260928/xbrl-sources-final.json --notes-manifest .tmp_earnings_v2_20260928/note-sources-2.json
```

附註清單為最多 12 筆的陣列，每筆只含 `path`、`sha256`、`url`、`observed_at`、`filing_sha256`。公司、期間及報表範圍由這次已解析且雜湊相符的結構化財報取得；不接受從清單傳入獲利數字或 `verified=true`。重複或不明確的財報參照拒絕處理。

清單與文件須在各自相同目錄，清單上限 16 KiB，單份文件 4 MiB，PDF 最多 120 頁、每頁抽出文字 50,000 字元、整份抽出文字 1,000,000 字元。這些是離線操作與輸出上限，不宣稱可防禦所有惡意 PDF 的解壓縮記憶體消耗；尚未作為產品檔案上傳入口。

預設只輸出 JSON；只有明確指定 `--output` 才寫一份新結果，最高 2 MiB。退出碼 `1` 是完成核對但整體來源關卡仍未過，`2` 是輸入／讀取／輸出失敗。已存在檔案不覆寫，沒有自動保存研究或假設。

新增解析器沒有寫檔、網路、計時器、背景工作、資料庫、瀏覽器儲存或遙測。PDF 文字只存在於記憶體；工具最多依使用者指定建立一份有大小限制的結果，不建立文字快取，不自動清理或覆寫。檔案量不會因待機而增加，限定本工具範圍的磁碟寫入風險為低。

本次開發樣本與測試產物仍在既有排除目錄；保留供重現，不進入正式金融資料、假設、核准或回測。回復只需停用可選附註參數，原有結構化財報稽核仍可使用，不涉及回滾使用者資料。
