# 我的股票與波段錨點輔助第一版

2026-09-30。依使用者確認順序開發；不包含安裝替換、提交或發布。

## 已確認的範圍與介入

1. 首頁「我的股票」列出持有、收藏、已保存研究，一鍵開啟個股研究。持有只是使用者標記，不記錄交易、數量、成本或損益。
2. 收藏沿用 research_watchlist_items；持有新增獨立本機資料表。已保存研究由既有不可變紀錄彙整。取消標記不刪除研究、不更動假設。
3. 波段輔助先揭露價格口徑、來源、資料日期及缺少的資格證據；將既有來源候選轉成可讀圖卡、日期價格清單與比較，再接現有預覽、待核准草稿、使用者核准、讀回及保存流程。不新增自動判浪或修改費波南希計算。

## 資料資格與候選規格

目前個股歷史價量來自 FinMind，未還原權息且交易日完整性尚未稽核。它可以供閱讀，不能直接生成已確認的自動錨點。現有來源候選是人工研究假設；圖卡只連接候選點，不是完整走勢或自動確認的波浪。未提供轉折確認日期時明示「未提供」，不得把轉折日期或來源發布日期當成確認日期。

每個波段候選最多三個錨點，保留角色、日期、價格、原始來源、理由、限制、版本。每項最多三份適用候選；不依潛在漲幅排序、不平均或取代系列。缺資料可以保存部分研究。候選版本改變時沿用現有伺服器版本核對，拒絕過期預覽／草稿；圖卡不改變來源資格。價格能力待補強與人工來源待查證分開呈現。

## 介面、儲存與風險

新增 /api/v2/research/library 讀取及明確設定標記介面；只允許已知標的或已有研究／自選紀錄的標的。沿用本機實例、來源、防偽造請求及 16 KiB 限制。寫入以預期狀態指紋與重複請求鍵保護，單一交易完成；重送已成功請求可讀回原結果。持有標記最多 5,000 個標的，命令最多 20,000 筆且內容合計上限 32 MiB，單筆命令與結果合計上限 16 KiB；額滿拒絕新增並回復本次交易，不背景清除。僅按鈕操作寫入，閱讀、切換分類不寫入、不抓外部資料。

新增式第 28 次遷移不修改既有表結構。先在隔離資料副本核對所有舊表內容，再驗證重跑遷移。RESEARCH_LIBRARY_ENABLED=false 隱藏新清單／拒絕標記寫入；RESEARCH_WAVE_ASSIST_ENABLED=false 退回原候選呈現。回復保留新增紀錄，不刪表、不撤銷核准。

## 驗證

焦點案例涵蓋標記獨立性、保存研究保留、既有收藏、重送／回應遺失、狀態衝突、容量上限、來源與本機防護、唯讀無寫入、波段缺資料／零量／時間與口徑限制、候選修訂／草稿／核准讀回，以及歷史模式。執行完整 Python 回歸、前端測試、型別檢查、程式檢查、建置；檢查 360、768、1024、1440 像素及鍵盤操作。正式使用者資料不供測試寫入。
