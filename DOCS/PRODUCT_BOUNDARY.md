# 產品定位與安全邊界

## 正式定位

本系統是供個人使用的台灣股票市場研究與決策支援工具。系統整理市場資料，提供技術面、基本面、籌碼面、總體分析、歷史回測、虛擬資金配置、風險警示與通知。

所有輸出皆為研究結果，不保證報酬，也不直接替代使用者的投資決策。

## 允許的能力

- 整理大盤與個股市場資料。
- 計算波浪、費波南希、均線扣抵、基本面估值及市場熱度。
- 使用歷史資料執行回測與虛擬資金配置。
- 產生分析訊號、風險警示及訊息通知。
- 使用 Backtrader 的模擬 broker、`buy`、`sell`、`close` 與 order 生命週期進行歷史撮合。

## 明確禁止的能力

- 不得連接券商帳戶或保存券商帳戶憑證。
- 不得引入券商 SDK、真實委託 API、跟單或自動交易出口。
- 不得送出真實委託單或管理客戶資金及持倉。
- 不得將研究訊號描述為保證報酬或必然交易指令。
- Backtrader 的訂單物件只能存在於歷史回測與虛擬交易模擬環境。

## 分析資料契約

- 真實資料不足時，回傳 `insufficient_data` 或 `not_applicable`，不得推造替代數值。
- 歷史分析只能使用 `as_of_date` 當時已發布的資料。
- 對外結果應保留資料日期、來源、單位、計算方式及適用限制。
- 事後完整區間視覺化必須與即時可用訊號分離，且清楚標示不可用於即時決策。
- 通知內容使用「研究」、「觀察」、「條件成立」或「風險警示」等語意，不得表述為真實委託指令。
