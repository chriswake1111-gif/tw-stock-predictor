# 自動波段研究候選第一版

本批交付「可閱讀、比較、明確選作人工草稿的真實候選」。這與既有自動波段資格檢查不同：原檢查仍針對原價格快照及歷史可知性；新候選以另存的官方證據包，供目前研究使用。人工核准及研究保存仍是獨立操作。

## 明確範圍與方法

首批只開放台積電 `2330.TW`，完整要求期間固定為 `2025-09-29` 至 `2026-09-30`。日期不是依轉折或報酬挑選，也不以縮短區間取得通過結果。其他股票或期間回傳 `unsupported`，須先完成另一批來源及適用資格評估。

這是 C 級專案操作化（`WAVE-CANDIDATE-01`、`PRICE-BASIS-01`），不是已驗證的杜金龍自動判浪方法；`official_affiliation=false`。人工核准後沿用的 `FB-04` 回檔公式，與自動尋找錨點的證據分類分開，不升格候選規則。

官方證據包包含逐月個股開高低收及成交股數、全市場成交日期、年度休市日、星期一至星期五的交易規則、經核對的臨時休市公告、停復牌表、除權息、減資及變更面額表。限定來源網址、查詢參數、回應欄位、股票、市場、月份、列數、日期及雜湊都必須通過。每個要求期間的工作日須有成交或休市證據，不將兩個來源同時漏日誤認為完整。

本批經逐筆核對的臨時休市原始公告為 [交易所 115 年 7 月 10 日休市公告](https://www.twse.com.tw/staticFiles/news/news/tsecnews/8a8216d69ef76943019f46cb86ae0110.pdf)，程式保存並校驗指定公告的官方識別、標題及附件定位。新增其他例外日需另外核對，不接受任意使用者網址。

公司行動表沒有資料，**不單獨等於沒有公司行動**。本批還要求每個官方成交日有有效正量開高低收，逐日漲跌價差能和前次收盤銜接；每個不比價 `X` 標記都須與支援的現金除息事件、前次收盤、官方參考價吻合，且事件也必須反向對上標記。減資、面額變更、其他權息型態、未知註記、停復牌事件、缺日或衝突均停止產生候選。這是本股票、本期間每日價格可比較性的有限證據，不宣稱公司行動全類型或盤中交易狀態均已完整覆蓋。

### 同一價格基準

只支援明確的現金除息。對事件前每一筆開高低收乘上：

`官方除息參考價 ÷ 官方除息前收盤價`

每筆價格的累積因子包含該筆日期之後、截至檢查截止日的所有適用事件。保留原始價格、各事件、因子及基準日；成交股數不換算。來源為 [交易所除權息參考價及計算說明](https://www.twse.com.tw/zh/announcement/ex-right/twt49u.html)。官方參考價保留兩位小數，對帳容許公布值截位產生的小於一分差額；不用另按升降單位取整的「開盤競價基準」取代參考價。

這是本專案對官方參考價的比例換算，不把衍生價格稱為官方成交價或官方還原價。不能和不同基準的行情混用；新的公司行動或來源修訂需要重新檢查。取得日期必須晚於各來源要求的完成日期，禁止當日未收盤資料進入本批證據包。

### 固定轉折與配對

只呼叫 `WaveFibonacciEngine.detect_confirmed_pivots`，固定往前五筆、往後三筆；不呼叫舊版整合價格推算。嚴格比較高低價，尾端不足三筆不能確認，同日雙向轉折不配對。同一轉折序列中只取相鄰低點→高點，終點大於起點；不先刪除中間轉折再跨越配對。最多顯示最近三組，依確認時間排列，不按漲幅或績效排名、不調參、不判第幾浪。

確認交易日、行情日期、實際取得時間分開。逐段重播只驗證固定快照追加資料後已確認轉折的一致性；不證明歷史當時取得過這份資料。候選固定回傳 `historical_backtest_eligible=false`，不寫入回測表、訊號或自動交易。

## 介面與流程

- 唯讀 `GET /api/v2/research/wave-candidates/{symbol}`：`wave_candidates_v1`，含要求／實際區間、證據版本、取得時間、價格基準、檢查、限制、最多三組候選；`Cache-Control: no-store`。
- 唯讀 `GET /api/v2/research/wave-candidates/{symbol}/{candidate_id}`：供既有錨點假設預覽的具體值。沒有合格的目前版本時不能取得可寫入值。
- 價格快照與證據版本在同一唯讀交易選取。新價格快照、最新來源失敗／撤銷、內容損壞均不退回舊候選。
- 使用既有假設預覽與草稿入口，保留候選版本參照。服務端重新計算並比對股票、錨點、規則、來源及理由；使用者不可改值卻仍宣稱引用原候選。既有寫入交易、本機實例、來源、防偽造請求及重送保護不變。
- 草稿成功只顯示待核准；核准及確認保存沒有新增助理命令。回應遺失可用相同請求鍵讀回原結果，不重複建立。新版本不移植舊核准，也不自動撤銷原人工假設。
- 保存預覽可包含 `wave_candidate_reference_v1`：不可變來源雜湊、取得時間、完整區間、基準、規則及限制。它是程式候選的證據，不偽裝成外部分析師報告。正式保存後保留固定內容；後續來源失效仍可閱讀原引用。
- 畫面在候選層並列日期、錨點及限制；原價及因子可展開。閱讀無採集、無自動草稿、核准或保存。切換股票取消舊讀取，歷史模式不讀目前候選。

研究助理命令：

```powershell
python -m src.research_assistant.cli wave-candidates 2330.TW
python -m src.research_assistant.cli wave-candidates 2330.TW --id <候選識別>
```

須使用相同版本的本機服務；舊安裝版能力不符時明確拒絕。來源端兩份研究技能已同步說明，安裝中的技能於後續正式升級處理。

## 有界取得、儲存與回復

工程操作工具必須指定資料庫、股票、完整區間及請求鍵。預設只列取得計畫，`--execute` 才連網和追加證據：

```powershell
python tools/update_wave_candidate_evidence.py --db <隔離資料庫絕對路徑> --symbol 2330.TW --start 2025-09-29 --end 2026-09-30 --request-key <唯一請求鍵>
# 檢視計畫後，只有明確的更新工作才加入 --execute。
```

不自動掃描收藏，不在頁面讀取、啟動或排程時採集。單次最長 180 秒，每來源最多重試一次；同範圍及價格版本 24 小時內預設沿用最近紀錄（包括查證失敗），有明確新事件或續查需求才 `--force`。相同請求鍵重送讀回相同版本。

遷移 `20261001_30_wave_candidate_packages` 只新增證據表、索引及防覆寫／刪除觸發器。單來源最多 2 MiB、單包含保守列開銷最多 6 MiB、邏輯總量最多 64 MiB；滿額停止新增，不自動清除。原始官方回應及內容雜湊保留，不保存私人對話。這是專用來源包，與原 16 KiB 助理摘要入口分開，沒有放寬既有寫入契約。

工具與讀取服務不建立不存在的資料庫、不執行遷移。正式升級前先備份並在隔離副本驗證；新增表不改原金融資料、研究、假設與核准。未來改解析器或演算法時須保留既有版本讀取器，不能以新規則重新解釋舊引用。

`RESEARCH_WAVE_CANDIDATES_ENABLED=false` 可退回原人工候選；既有 `RESEARCH_GUIDANCE_ENABLED`、`RESEARCH_WAVE_ASSIST_ENABLED` 仍有效。停用不刪證據表、不撤銷假設、不改歷史研究。

## 後續開放順序

1. 逐一擴展其他股票／期間的來源適用、上市生命週期、休市例外及公司行動證據；不得因本試點通過而全市場開啟。
2. 支援其他事件種類前，先做原始數字及換算方法對帳與版本隔離，尤其減資、分割、合併事件。
3. 累積真正歷史可知時間證據後，再獨立評估即時確認／回測資格；目前候選不能直接挪用。
4. 評估薄型模型內容協定（Model Context Protocol）工具包裝既有介面，分離閱讀、更新和草稿；先量測往返、回應大小及耗用，不預先宣稱節省比例。
