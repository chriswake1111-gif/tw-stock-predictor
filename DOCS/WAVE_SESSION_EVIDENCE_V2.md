# 官方交易日與停復牌證據補強：第二版

本批延續 [第一版資格檢查](WAVE_QUALIFICATION_V1.md)，補強「現在回頭核對指定期間」的日期證據。不是自動波段資格升格；正式自動候選仍關閉，人工候選、核准、研究保存、金融公式與回測不變。

## 使用者流程

個股頁的「波段資料：現在能讀什麼」新增「交易日與停復牌：目前確認到哪裡」。先看官方曾有成交、缺行情、缺證據、資料衝突及主要下一步，再展開日期例子、完整分類、來源區間與取得時間。

- 「官方有成交」只證明該來源曾記錄成交，不證明全日正常交易，也不驗證第三方最高／最低價。
- 「缺行情」只在官方已有個股成交證據、而本機價格快照缺該日期時成立。
- 「缺證據」不等於休市、沒有事件或資料正常。週末也不自行推定休市。
- 暫停交易及恢復交易必須有明確時間，且已經過該事件時間，才可用於有界時段判讀。未配對、時間不明、同時相反事件、盤中變動均不能冒充整日停牌。
- 13:30 正好恢復仍不視為整日停牌；本版保守處理收盤邊界。停牌日數描述暫停時段涵蓋一般交易時段的日期，不另外宣稱那些日期均已取得市場開市證據。
- 分類可能重疊，不能相加當作總日數。完整分類表與日期例子收在展開區。
- 「最近一份證據取得時間」是本次來源取得時間；歷史當時可用性一律尚未證明。
- 複製查證需求只複製文字；不啟動 Codex、背景搜尋、更新、核准或保存。剪貼簿失敗會展開並選取唯讀文字。
- 重新檢核只讀本機證據。歷史研究維持原保存內容，不套用目前結果。

沒有新增使用者填數字、核准資格或評分介面。既有資料日期與更新失敗提示繼續保留。

## 來源契約與涵蓋限制

固定允許下列官方端點，依股票市場選取，來源網址不接受使用者自訂。年月、代號、欄位及筆數等契約不符合時，留下失敗紀錄，不採用數值。

| 來源 ID | 官方端點 | 使用範圍及限制 |
|---|---|---|
| twse_market | `www.twse.com.tw/exchangeReport/FMTQIK` | 月資料；正成交量及成交金額證明市場曾交易，不從缺列推定休市。 |
| twse_stock | `www.twse.com.tw/exchangeReport/STOCK_DAY` | 月資料；核對股票、月份、欄位與筆數，正成交量／金額及完整正價格僅產生「曾成交」日期。 |
| twse_holiday | `www.twse.com.tw/rwd/zh/holidaySchedule/holidaySchedule` | 年資料；只採明列休市日期，不自動補週末或臨時休市。 |
| twse_halt | `www.twse.com.tw/rwd/zh/afterTrading/TWTAWU` | 原區間分年查詢；暫停／恢復名單不能代表所有停止買賣原因。 |
| tpex_stock | `www.tpex.org.tw/www/zh-tw/afterTrading/tradingStock` | 月資料；核對股票與筆數，只採正值成交及完整價格所對應日期，不匯入價格。 |
| tpex_holiday | `www.tpex.org.tw/www/zh-tw/bulletin/tradingDate` | 年資料；核對表格標題年。`endDate` 是最新可查年份，不能當成本次內容年份。只讀完整獨立單日儲存格；跨日文字、合併列與債券專屬列不推算。 |
| tpex_halt | `www.tpex.org.tw/www/zh-tw/bulletin/sprcHis` | 年資料、`cate=1`；只取指定股票的上櫃股票事件，不從空名單推定正常交易。 |

原始官方查詢可包含同一月份／年度的其他日期或股票；本地判讀只採指定股票與原要求區間的日期。股票狀態事件可作為有界停復牌配對佐證，但不延續沒有恢復證據的停牌事件。原始來源只是證據，不進入標準化金融資料表。

來源契約於 2026-09-30 以官方回應及官方網頁使用的端點核對。TWSE 的[暫停及恢復交易](https://www.twse.com.tw/zh/trading/historical/twtawu.html)與[停止及恢復買賣](https://www.twse.com.tw/zh/listed/violations/stop.html)各有涵蓋範圍，不能合稱所有停牌原因均已涵蓋。網頁改版時應修訂解析版本及測試，不能放寬解析以取得通過。

上市日期只沿用既有可見的初次上市證據，不把今天的股票主檔當作整段歷史正常交易狀態。既有官方日曆仍沿用市場、時間、修訂與撤銷限制。

## 介面與資料契約

沿用唯讀 `GET /api/v2/research/wave-qualification/{symbol}`，在 `wave_qualification_v1` 增加可選 `session_coverage`，其版本為 `wave_session_coverage_v1`。整份結果仍來自同一個唯讀交易；無新網頁寫入介面。

包含原要求區間、查證時間、最近取得時間、分類總數、最多 8 個日期例子、最多 12 個來源修訂參照、限制、負責者、下一步及可複製需求。優先列出衝突與確知缺行情日期，避免大量未知日期遮住可處理問題。來源摘要有上限，不是完整來源清單；完整修訂留在本機證據表。

`mode=retrospective_local`、`historical_availability=not_asserted`。子區塊 `available` 只表示取得日期佐證；正式「交易日與交易狀態」檢查仍不能升為已確認。缺行情或矛盾為未通過，其他未完整涵蓋情況為尚無證據。`automatic_candidates_eligible` 永遠是 `false`。

完整性／讀取錯誤時整體「暫時無法檢查」，移除部分成功的子結果，不退回舊快照。結果不進入保存內容或確認指紋，也不改寫歷史研究。前端純文字呈現來源，不載入來源網址或執行內容。

## 獨立證據紀錄

新增式遷移 `20260930_29_wave_session_evidence` 只建立 `wave_session_evidence`、索引與不可更新／刪除觸發器。內容包括股票、市場／來源定位、要求區間、取得時間、原始及標準化證據、內容雜湊、重送鍵與前版參照。

- 接受的資料保存有上限的原始官方回應及解析結果；不保存使用者筆記、對話、憑證。
- 更新工具另保存實際回應位元組 SHA-256 與 HTTP 狀態；失敗回應不保存任意 HTML／例外文字，只保留來源定位、時間、失敗原因及能取得的回應雜湊。連線失敗時回應雜湊可缺，不捏造。
- `raw_sha256` 是 UTF-8 解碼後文字的雜湊；`response_sha256` 是傳輸回應位元組雜湊，兩者不混用。手動測試／舊本批驗證紀錄可沒有後者。
- 讀取重新驗證雜湊、來源綁定、解析內容及取得時間；不允許未來成交日期偽裝為已取得事實。
- 相同請求鍵重送沿用原結果；新查詢只追加修訂。最新重疊區間查詢失敗或撤銷時不復活舊證據。
- 不移植人工核准，不寫入官方金融表、假設表、核准表、研究表或回測表。
- 納入既有重要證據備份／還原清單；來源版本後續若改變，需要相容讀取舊版或明確阻擋，不能靜默重新解釋舊紀錄。

`SESSION-EVIDENCE-01:1.0.0` 登錄為 C 級專案操作化規則，只允許回溯資料品質診斷，不是杜金龍已驗證核心。

## 明確執行的本機更新工具

```powershell
# 預覽，不連網、不建立資料庫、不遷移、不寫入。
python -B -X utf8 tools/update_wave_session_evidence.py --db PATH_TO_COPY_DB --symbol 9911.TWO --start 2026-09-01 --end 2026-09-30 --request-key unique-operation-20260930

# 確認工具範圍後加 --execute；只追加該股票／區間的獨立證據。
python -B -X utf8 tools/update_wave_session_evidence.py --db PATH_TO_COPY_DB --symbol 9911.TWO --start 2026-09-01 --end 2026-09-30 --request-key unique-operation-20260930 --execute
```

要求既有且已完成本批遷移的資料庫。首批只支援四位數 `.TW`／`.TWO` 股票，最多 1,101 個日曆日、120 個請求；不擅自縮短區間。單次操作最多 180 秒，每請求透過既有嚴格來源與傳輸保護，有限重試。超時保留已完成結果並列出未執行項目，不循環補抓。

同來源、股票、精確範圍在 24 小時內有成功／失敗紀錄時，預設保留。明確續查使用新的 `--request-key --force`；可加 `--source tpex_holiday`，只重查指定來源，不重抓其他月份。相同請求鍵永遠優先重播，`--force` 不會覆寫。多個程序同時使用同一鍵可能在寫入前重複唯讀查詢，但唯一鍵阻止重複儲存；遇衝突重送可讀回已保存的紀錄。

結束碼 0 表示操作完成（不代表資格合格）、1 有來源失敗或未執行、2 輸入或本機操作錯誤。工具不接受任意網址，也不掃描收藏；沒有啟動、排程或 UI 讀取連動。

## 遷移、驗證與回復

開發只在正式資料庫的 SQLite 備份副本執行遷移與來源追加。舊表逐表筆數及內容雜湊核對；原有研究、假設與核准不變。實際三檔私人盤點及原始報告只留在忽略的本機目錄，不提交。

`RESEARCH_WAVE_SESSION_EVIDENCE_ENABLED=true` 預設開啟。設為 `false` 回到第一版資格說明，更新工具也停止接受新工作；新增表與紀錄保留。舊資料庫尚無新表時可正常唯讀，顯示未取得新證據，讀取不自動遷移。仍受原波段及資格功能開關限制。關閉功能不會中斷已經開始的命令，緊急回復先等待或停止該命令。

本批沒有替換安裝版、提交、推送或發布。將來安裝升級前仍使用既有備份／遷移流程。使用者研究資料不刪除；不要用刪表回復。

詳細測試、環境限制、資料保護與磁碟寫入盤點見 [第二版驗證紀錄](WAVE_SESSION_EVIDENCE_V2_VALIDATION.md)。

2. 公司行動與價格基礎：先證明期間覆蓋及事件，再設計可追溯還原因子；本版沒有新增價格還原。

4. 資格合格資料的隔離重播，再另案設計正式候選；不因本次查詢成功或固定資料測試通過就開放自動判浪。
