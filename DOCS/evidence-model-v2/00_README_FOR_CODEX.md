# 杜金龍公開方法證據化模型 v2：Codex 執行入口

## 任務目的

在現有 `tw-stock-predictor` Repository 中，平行建立一套：

> **杜金龍公開方法的證據化決策輔助模型**

本次不是繼續擴充現有「杜金龍量化預測」骨架，也不是追求自動複製杜金龍本人判斷。實作必須嚴格區分：

1. 有一手證據且可重現的規則。
2. 有公開使用案例但需參數化或人工核准的規則。
3. 本專案為了工程化而新增的操作定義。
4. 缺乏證據、不得冠名為杜金龍方法的實驗功能。

## 最高優先原則

1. 不得把歷史 TTM EPS 假裝成未來 EPS。
2. 不得把 U 級規則放入核心評分、交易訊號或「杜金龍模型」輸出。
3. 不得自動判浪後直接產生買賣指令。
4. 不得使用未公開的 EVA 公式計算「杜金龍 EVA 底價」。
5. 不得使用固定 2.5 兆、7%～11%、20／30／50、爆量延後進場作為杜氏通則。
6. 所有分析均須保留 `as_of_date`、`available_at`、來源、規則版本與人工覆寫紀錄。
7. 新模型先以 `/api/v2` 平行提供，舊 `/api/analysis` 暫時保留，不得一次性重寫全部功能。
8. 回測與歷史重播只能使用當時已經公開、`available_at <= as_of_date` 的資料。
9. 所有目標價均輸出情境區間與失效條件，不輸出保證性結論。
10. 本系統不連接券商、不送出真實委託。

## Definition of Done

v2 只有在以下條件全部成立後才可被稱為「核心模型候選版」：

- 規則註冊表可追溯證據層級。
- Forward EPS 與歷史 TTM EPS 完全分流。
- M1B 比率使用正確單位及公告日期對齊。
- 波浪與費氏錨點必須人工核准或明確標示為候選。
- 三等份只作資金部署規劃，不因不完整訊號自動買進。
- U 級規則無法進入核心綜合結論。
- 分析快照不可覆寫，可重現當時輸出。
- CI 通過全部單元、整合、Prefix Invariance 與 Look-ahead 測試。
