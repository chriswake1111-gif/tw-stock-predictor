# Phase 9 UI Information Architecture

Navigation is intentionally non-evaluative: 市場概況、個股研究、歷史快照、歷史觀察、模型說明。

The stock route `/stocks/:symbol` orders information as symbol/cutoff/status, independent dimensions, valuation scenarios, target-range confluence, technical support, screening, virtual deployment, and evidence trace.

Deep links are supported for stock, exact snapshot and exact evaluation run. The interface has no recommendation, ranking, trading or administration route.

Desktop uses persistent left navigation and an evidence drawer. Mobile preserves the same content order with bottom navigation; evidence remains text-readable without charts.
