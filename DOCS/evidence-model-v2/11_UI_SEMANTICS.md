# Phase 9 UI Semantics

- **研究證據等級** describes public-source support for a rule. It is not historical performance or accuracy.
- **方法匯聚程度** describes structural overlap among relatively independent approved target methods. It is not prediction confidence.
- **歷史觀察** describes outcomes in defined samples. Historical target reach observation is not future probability.

Historical reconstruction is not an actual historical publication. FB-04 is support, not a target. Quality warning is not a target miss or model failure. Partial means usable sections coexist with incomplete sections. Target ranges are scenarios, not guaranteed prices.

Unknown server statuses render `Unknown analysis state`. Missing values remain missing; React does not fill or reinterpret them. Current price is outside Phase 9 MVP and the frontend is read-only.
